# Julnius Harefa Portfolio

Website portofolio statis menggunakan HTML, CSS, dan JavaScript murni.

## Menjalankan di komputer
1. Ekstrak folder ZIP.
2. Buka folder `julnius-portfolio` di Visual Studio Code.
3. Pasang ekstensi **Live Server** jika belum tersedia.
4. Klik kanan `index.html` lalu pilih **Open with Live Server**.

## Struktur folder
- `index.html` : isi dan struktur website
- `css/style.css` : desain, layout, dan responsive
- `js/main.js` : navigasi mobile dan animasi saat scroll
- `assets/` : foto dan dokumentasi portofolio

## Publikasi dengan Vercel
1. Buat repository baru di GitHub.
2. Upload seluruh isi folder proyek ke repository tersebut.
3. Login ke Vercel menggunakan akun GitHub.
4. Pilih **Add New → Project**, lalu impor repository.
5. Untuk proyek HTML statis ini, biarkan Framework Preset sebagai **Other**.
6. Biarkan Build Command dan Output Directory kosong, lalu klik **Deploy**.
7. Setelah deployment selesai, Vercel akan memberikan URL publik.

Catatan:
- Periksa kembali informasi kontak dan tautan sosial sebelum dipublikasikan.
- Jika ingin mengganti gambar, simpan file baru di folder `assets` lalu ubah nama file pada `index.html`.
